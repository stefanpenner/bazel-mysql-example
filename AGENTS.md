# Agents

When you change a file that `README.md` links to, update that link in the same change.

A link has the form `path#Lstart-Lend`. The range must include the lines that do the named job. After the code moves, the old numbers are wrong.

Before you finish:

1. Read every link in `README.md`. The link text names the job. The target is `path#Lstart-Lend`.
2. Open that range.
3. Confirm those lines still do that job.
4. If the code moved, set the range to the new lines.
5. If a README sentence is no longer true, update the sentence and the impact. Do not keep a number the code no longer supports.

Do not keep a second list of these links.
